# Задача 2. Anagrams

## 1. Объяснение решения

**Обозначения.** `n` — число слов, `l_i` — длина `i`-го слова, `L = Σ l_i` — суммарная длина всех слов, `M = max l_i` —
максимальная длина слова.

### Наивный подход через сортировку

Анаграммы — это слова, состоящие из одного и того же набора букв. Значит, если каждое слово отсортировать по буквам,
анаграммы дадут одинаковую строку, и её можно использовать как ключ:

```python
key = ''.join(sorted(s))
```

Группируем слова в словаре `{key: [слова]}`.

Стоимость: сортировка слова длины `l_i` занимает `O(l_i log l_i)`. Суммарно по всем словам:

$$T_{\text{sort}} = \Theta\!\left(\sum_{i=1}^{n} l_i \log l_i\right) = O(L \log M) = O(n M \log M)$$

### Подход без сортировки

Сортировка не обязательна. Достаточно посчитать, сколько раз каждая буква встречается в слове, и использовать этот
«частотный портрет» как ключ. Анаграммы имеют одинаковый портрет, разные наборы букв — разный.

```python
freq = {}
for c in s:
    freq[c] = freq.get(c, 0) + 1
key = frozenset(freq.items())
```

`freq` — это `dict` вида `{буква: количество}`. `frozenset(freq.items())` превращает его в неизменяемое множество пар
`(буква, количество)`, которое можно использовать как ключ словаря. `frozenset` не зависит от порядка вставки букв,
поэтому `"eat"` и `"tea"` дадут одинаковый ключ без всякой сортировки.

Стоимость: подсчёт частот — `O(l_i)`, построение `frozenset` из `d_i` уникальных букв — `O(d_i) ≤ O(l_i)`. Суммарно по
всем словам:

$$T_{\text{freq}} = \Theta(L) = O(n M)$$

## 2. Оценка сложности

**Время:** `O(L)` в среднем, где `L = Σ l_i` — суммарная длина всех слов.

- Один проход по всем словам и их буквам — суммарно `L` итераций.
- На каждой букве: `freq.get` и `freq[c] = ...` — `O(1)` в среднем.
- На каждом слове: построение `frozenset` из `d_i` пар — `O(d_i) ≤ O(l_i)`.
- Вставка в `groups`: `try/except` с `append` — `O(1)` амортизированно.

Итого `Σ O(l_i) = O(L)`. В терминах `n` и `M` это `O(n M)`, но оценка через `L` точнее: она учитывает, что слова могут
быть разной длины.

**Дополнительная память:** `O(L)`.

- Словарь `groups` хранит все слова — их суммарная длина как раз `L`.
- Ключи словаря: `frozenset` на каждую группу. В худшем случае (все слова уникальны) суммарный размер ключей —
  `Σ d_i ≤ L`. В лучшем (все анаграммы) — один ключ размера `O(M)`.
- Временный `freq` для текущего слова — `O(M)`, переиспользуется между итерациями.

## 3. Визуализация работы алгоритма

Возьмём `strs = ["ab", "ba", "abc", "cab", "x"]`. Ожидаемые группы: `[["ab", "ba"], ["abc", "cab"], ["x"]]`.

Каждая строка таблицы — состояние **после** обработки слова. `key` записан как множество пар `(буква, количество)` для
наглядности; в коде это `frozenset`.

| Шаг |  Слово  | `freq`            | `key`                        | `groups` после шага                      |
|:---:|:-------:|-------------------|------------------------------|------------------------------------------|
|  1  | `"ab"`  | `{a:1, b:1}`      | `{(a,1), (b,1)}`             | `{K1: ["ab"]}`                           |
|  2  | `"ba"`  | `{b:1, a:1}`      | `{(a,1), (b,1)}` = K1        | `{K1: ["ab", "ba"]}`                     |
|  3  | `"abc"` | `{a:1, b:1, c:1}` | `{(a,1), (b,1), (c,1)}` = K2 | `{K1: ["ab", "ba"], K2: ["abc"]}`        |
|  4  | `"cab"` | `{c:1, a:1, b:1}` | `{(a,1), (b,1), (c,1)}` = K2 | `{K1: ["ab", "ba"], K2: ["abc", "cab"]}` |
|  5  |  `"x"`  | `{x:1}`           | `{(x,1)}` = K3               | `{K1: [...], K2: [...], K3: ["x"]}`      |

Что здесь важно:

- На шаге 2 порядок букв в `freq` другой (`b` идёт перед `a`), но `frozenset` игнорирует порядок — ключ совпадает с K1.
  Сортировка в этом месте не нужна.
- На шагах 3–4 то же самое: `freq` для `"abc"` и `"cab"` строится в разном порядке, но множество пар одинаковое.
- На шаге 5 у слова `"x"` ключ не совпадает ни с одним существующим — создаётся новая группа. Для этого используется
  `try/except KeyError` вместо `if key in groups`: при большом числе попаданий это дешевле, потому что исключение
  возбуждается только на новых ключах, а их не больше числа групп.

Результат: `list(groups.values()) = [["ab", "ba"], ["abc", "cab"], ["x"]]`. Порядок групп и слов внутри групп зависит от
порядка первого вхождения в `strs`; по условию конкретный порядок не требуется.
